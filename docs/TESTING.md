# 测试

三层验证，各管一件事，互不替代。

| 层 | 命令 | 数量 | 耗时 | 管什么 |
|---|---|---|---|---|
| 单元（Node，无浏览器） | `npm test` | 79 | < 1 s | 几何拓扑、确定性、参数敏感性、编码、着色器静态检查 |
| 端到端（浏览器） | `npm run test:e2e` | 26 | ≈ 2 min | 着色器能否编译、渲染像素是否随参数变化、导出、稳定性 |
| 像素审阅（截图） | `npm run shots` + `node scripts/review-shots.mjs` | 34 | ≈ 2.5 min | 交付截图的画面质量 |

## 1. 单元测试（79 项）

### `test/geometry.test.js`（16 项）

- 二十面体：顶点/面数公式 `10·4^L+2` / `20·4^L`；欧拉示性数 = 2（L0–L5）；全部顶点精确落在单位球上（误差 < 1e-9）；邻接表**恰好为 2E**、无空洞、无自环、无重复且对称。
- 噪声：同种子逐位一致（400/400）、不同种子 380+/400 不同；范围在 [−1,1] 且零均值；**格点处不为零**（偏移修复的回归测试）。
- fBm / ridged 值域；域扭曲确实位移采样点。
- 种子：同字符串同流一致、不同流不同、9 条流互不相同、FNV-1a 雪崩性（32 位中至少 10 位翻转）、数字 seed 与同形字符串 seed **刻意不等**。

### `test/heightfield.test.js`（27 项）

- 板块：每顶点唯一有效归属；**连通性**（连通分量数 = 板块数，防止退化为距离分配）；面积均衡（最大/最小 < 4×）；边界顶点数随板块数单调增长。
- 确定性：同 seed 高度**逐位相同**（不是"接近"）；不同 seed 分离；`seed` 与 `seed2` 不混叠。
- **参数敏感性（9 项，逐参数）**：`plateCount / plateHeight / mountainHeight / ridgeSharpness / riftDepth / noiseScale / warpStrength / detailAmplitude / erosionIterations` 各自独立验证"改变顶点高程"。
- `continentBias`：5 个取值误差 < 0.005；单调性；海平面重锚后严格为 0；海洋掩码与高程符号一致。
- 侵蚀：质量守恒（转移不产生/消灭物质）；0 迭代不改动。
- 法线：单位长度、外向（dot > 0.2）；无起伏时严格径向（dot > 0.9999）。

### `test/params-export.test.js`（25 项）

- schema：键唯一、组非空、range 定义自洽（含**默认值必须落在步长格上**，否则首帧会被吸附而静默变值）、颜色合法、`seed`/`detail` 标记为需重建。
- URL：往返一致、默认值省略、颜色去 `#`、未知键忽略、越界**钳制**、非法值回退、布尔接受 `true/1`。
- 云量：5 个取值实测误差 < 0.02；单调且覆盖 0→1；分位数确定性。
- 星空：数量、种子一致；`bandStrength` 使带内占比上升；全部星点落在设定半径上。

### `test/shader-uniforms.test.js`（3 项）

- 每个被 GLSL 引用的 `uXxx` 都有声明。
- 每个 uniform 字典键都被 GLSL 引用（防拼写漂移）。
- GLSL 字面量中无 `${` 模板残留。

### `test/template-guard.test.js`（8 项）

- 7 个含 GLSL 的源文件内无反引号泄漏（反引号会提前终止 JS 模板，报错位置在下游很远处，极难定位）。
- 扫描器自检：能识别被反引号切断的字面量。

## 2. 端到端（26 项）

`npm run test:e2e`，Chromium + SwiftShader。

| 类别 | 检查 |
|---|---|
| 运行时 | 无 JS 异常；**无着色器编译错误**（匹配 `Shader Error / VALIDATE_STATUS / not compiled`，不匹配含 "shader" 的普通日志） |
| 渲染 | 画布非黑（> 12%）；色彩桶 > 60（非单色） |
| 几何 | `relief > 0.02`；L5 顶点/面数精确 |
| 确定性 | 换种子再换回，签名完全一致；不同种子差异显著 |
| 参数→像素 | 山脉高度（几何 + 像素 sha1）、陆地占比（0.22/0.78 精确）、海洋开关、海洋颜色、云量、大气开关+强度、环带开关+倾角、太阳方位（亮度差）、星空开关+亮度、相机视角 |
| 档位 | L6 生成 40962 顶点且画面正常（> 20 KB PNG） |
| 导出 | GLB 魔数 `glTF` 且 > 100 KB；场景 JSON 含参数与实测值 |
| 稳定性 | 24 次快速参数变更后场景仍有效；连续重建 3 个种子无崩溃 |
| 响应式 | 414×860 无横向溢出 |

## 3. 像素审阅（34 项）

`npm run shots` 生成 `docs/images/*.png` 与 `capture-meta.json`（含投影盘面半径、实测几何、全部参数），随后 `node scripts/review-shots.mjs` 断言：

- 每张：盘面半径 > 150 px、色彩桶 > 80、盘面与深空可区分（**双向**，因为背光星球比背景更暗是正常的）。
- 大气：`hero / planet-day / planet-terminator / ocean-world` 边缘峰值高于天空；`planet-day` 昼侧边缘亮于夜侧。
- 晨昏线：左右半盘亮度差 > 10。
- 预设：arid 与 ocean 的 **R−B 符号相反**（暖/冷倾向相反）。
- 细节：L6 近景方差 ≥ L5 中景 − 6。
- 元数据交叉校验：hero 为 L5 拓扑且 relief > 0.05；L6 为 40962 顶点。

### 为什么盘面半径来自元数据而不是图像检测

试过三种图像检测，全部失败，且原因具体：

| 方法 | 失败原因 |
|---|---|
| 中心行扫描找连续亮区 | 行星环横穿同一扫描线；背光时盘面比天空暗，被判为天空 |
| 亮度阈值 + 连通域 | 背景噪声让掩码膨胀到几乎整帧 |
| 直方图中位数当天空 | 近景时盘面占多数像素，中位数落在行星上 |

最终方案：拍摄时用投影公式 `r = tan(asin(R/d)) / tan(fov/2) · H/2` 记录，审阅时直接使用。这是唯一在这 7 种构图下都成立的方案。

## 4. 本轮发现并修复的真实缺陷

按发现顺序，全部有实测数据，不是推测。

| # | 缺陷 | 表现 | 根因 | 修复 |
|---|---|---|---|---|
| 1 | 二十面体细分 O(n²) | L5 562 ms，L6 3657 ms | 每插入中点复制整个 `Float64Array` | 预分配精确顶点数，一次填充 → 38 / 146 ms |
| 2 | 邻接表残留 `-1` | 侵蚀读到无效邻居 | 按每三角形 2 槽位分配再去重 | 先去重无向边再建 CSR，`length === 2E` |
| 3 | 3D Simplex 格点恒为 0 | 球面采样出现零值斑点 | 单形体四顶点梯度贡献抵消（算法固有） | 采样空间加种子派生的无理偏移 |
| 4 | 陆地占比不精确 | bias 0.52 → 实际 0.511；0.20 → 0.166 | 侵蚀改变高度分布后海平面未重锚 | 侵蚀后二次定位海平面，误差 < 0.01% |
| 5 | 云量滑块呈开关状 | 0.52 → 37%，0.70 → 88% | fBm 输出集中在均值，固定阈值 | CPU 端排序噪声场，coverage 转分位数阈值（线性误差 0） |
| 6 | 银河带未聚簇 | `bandStrength` 无效果 | 挤压方向向量后被归一化，角度只缩到 81% | 按"经度 + 显式小纬度"直接构造带 |
| 7 | 环带着色器类型错误 | 整块环带编译失败但容器仍报"已渲染" | `float toCam = normalize(vec3)` | 删除未使用变量 |
| 8 | 大气均匀笼罩全屏 | 空白天空亮度 103–140 | 解析求交后 `tExit=0`、`stepLen≈0`，采样挤在相机附近；`discard` 未生效 | 用 `hit` 因子收敛，去掉 `discard` |
| 9 | 大气亮度随步数变 | 4/14/28 步 → 13/109/110 | 累加器随步长缩放 | 输出乘 `uSteps` 抵消 |
| 10 | 背光侧行星变纯黑 | 盘面亮度 0.6，σ 2.5 | 全弦积分把采样埋在行星体内，太阳项处处为暗 | 恢复全弦 + 夜侧环境光下限；边缘峰值 10 → 85 |
| 11 | 大气冲刷地表色 | arid 预设盘面 RGB [213,216,233]（蓝白） | 面朝视线的加成过大 | 面朝分量 0.012 → 0.0025；边缘权重重新配平 |
| 12 | `uAmbientSky` 未声明 | 大气整块编译失败，像素断言仍全绿 | 声明没写进 GLSL，只加进了 uniforms 字典 | 补声明；新增 `shader-uniforms.test.js` 静态守卫（已反向验证能被检出） |
| 13 | e2e 假报"种子不可复现" | 换回原种子签名不同（−6.67 vs −5.10） | 测试等的是重建前就已为 `true` 的 `ready` 标志 | 重建前先置 `false`；直调验证确定性成立 |
| 14 | GLSL 模板内反引号 | JS 语法错误报在几百行之后 | 注释里写了 `` `continue` ``（3 次） | 去掉反引号；新增 `template-guard.test.js` |

其中 #7、#12 是同一类问题的两个实例：**着色器失败不阻塞构建**。它们促成了静态守卫（#12 的修复项），这类缺陷现在会在 `npm test` 阶段暴露，而不是等到浏览器。
